# 🚀 Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website built with standard web technologies. Designed to showcase projects, technical skills, background, and contact information seamlessly across desktop and mobile devices.

---

## 🌟 Features

* Responsive Design: Optimized for all viewport sizes (mobile phones, tablets, and desktop displays).
* Hero Section: Introduction featuring dynamic text styling and clean call-to-action buttons.
* About & Skills: Visual breakdown of technical competencies with custom animated style components and skill percentage bars.
* Projects Overview: Showcase section highlighting recent applications and code repositories.
* Education & Contact: Dedicated sections containing academic history and a direct message form.

---

## 🛠️ Built With

* HTML5 – Markup and structural foundation.
* CSS3 – Custom styling, Flexbox, Grid, animations, and media queries.
* FontAwesome – Scalable vector icons.

---

## 📱 Mobile Responsiveness

The layout handles viewport scaling dynamically:
* Single-column stacking for mobile viewports.
* Flexible container adjustments to prevent horizontal scrolling.
* Touch-friendly navigation and interactable elements.
